StockRoom - Inventory Management (React + Django)

FIRST TIME ONLY
1. Double-click 1-INSTALL-first-time-only.bat and wait until it says DONE.

EVERY TIME YOU WANT TO USE IT
2. Double-click 2-RUN-backend.bat      (keep the window open)
3. Double-click 3-RUN-frontend.bat     (keep the window open)
4. Open http://localhost:5173 in Chrome

Folders:
backend  = Django (stores the data)
frontend = React  (the screens you see)
